# 개발자 프로필 웹사이트 PRD

## 1. 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | DemoPort |
| 목적 | 개발자 김종균의 역량과 작업물을 소개하는 개인 프로필(포트폴리오) 웹사이트 |
| 개발자 | 김종균 |
| 이메일 | jjohnkkim@gmail.com |
| 주 개발 분야 | 바이브코딩, Python, HTML5 |
| 문서 상태 | 초안 (v0.1) |

## 2. 배경 및 목표

### 배경
AI와 함께 코드를 만드는 바이브코딩을 중심으로 Python, HTML5 작업을 해 왔으며, 이를 한곳에서 보여 줄 공식 소개 페이지가 필요하다.

### 목표
1. 방문자가 10초 안에 "누구이며 무엇을 하는 개발자인지" 파악할 수 있다.
2. 작업물(데모)을 직접 실행하거나 확인할 수 있다.
3. 협업·의뢰 문의를 이메일로 쉽게 받을 수 있다.

### 성공 지표
- 프로젝트 섹션 클릭률
- 이메일 문의 클릭 수
- 모바일/데스크톱 Lighthouse 점수 90 이상

## 3. 대상 사용자

| 사용자 | 니즈 |
|---|---|
| 채용 담당자 / 팀 리더 | 기술 스택과 실제 결과물을 빠르게 확인 |
| 프리랜스 의뢰인 | 작업 스타일, 가능 분야, 연락 방법 |
| 동료 개발자 | 바이브코딩 사례와 코드 참고 |

## 4. 범위

### 포함 (MVP)
- 단일 페이지 정적 웹사이트 (HTML5, CSS3, JavaScript)
- 섹션: 히어로, 소개, 기술 스택, 프로젝트, 연락처
- 반응형 레이아웃 (모바일/태블릿/데스크톱)
- 라이트/다크 테마

### 제외 (추후)
- 블로그, 로그인, 백엔드/DB
- 다국어 지원 (2차에서 영어 추가 검토)

## 5. 기능 요구사항

### 5.1 히어로
- 이름 "김종균", 한 줄 소개 (예: 바이브코딩으로 아이디어를 빠르게 제품으로 만드는 개발자)
- 주요 버튼: "프로젝트 보기", "연락하기"

### 5.2 소개 (About)
- 개발 철학과 작업 방식 (AI 협업 기반 개발, 빠른 프로토타이핑)
- 짧은 경력/학습 이력 (내용은 본인 제공 후 반영)

### 5.3 기술 스택
- 바이브코딩: AI 코딩 도구를 활용한 기획 → 구현 → 개선 워크플로
- Python: 스크립트, 자동화, 게임/도구 제작
- HTML5: 시맨틱 마크업, Canvas, CSS3, JavaScript
- 각 항목은 카드 형태로 설명과 대표 사례를 함께 표시

### 5.4 프로젝트
- 카드 목록: 제목, 설명, 사용 기술 태그, 링크(데모/소스)
- 초기 항목 예시
  - 뱀 게임 (Python, tkinter): 사람 vs AI 대결
  - 테트리스 (HTML5 Canvas, JavaScript)
- 항목은 데이터 배열(JS)로 관리해 추가가 쉽도록 구성

### 5.5 연락처
- 이메일: jjohnkkim@gmail.com (mailto 링크, 클릭 시 복사 기능)
- 추후 GitHub 등 링크 추가 가능

### 5.6 공통
- 상단 고정 내비게이션 및 부드러운 스크롤
- 다크/라이트 전환 토글 (시스템 설정 기본 반영)
